Datasets
========

The datasets listed below are bundled with the package. Each page describes the features and
targets, gives the source with a ready-to-use citation, states the license and the changes
made to the data, and shows how to load it.

Only datasets with an explicit **CC0 1.0** or **CC BY 4.0** license are bundled, see
:doc:`/license` for the reason and for how this is checked.

.. include:: /_generated/datasets_table.inc

Missing values are stored as ``NaN``. A dataset says whether it has any before you load it:
``get_info(name).has_missing``.
